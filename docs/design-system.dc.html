왜 이 색과 톤인가
  1. 사진이 주인공이므로 UI 색은 전부 채도를 낮췄다. 원색은 화면에 한 점도 없고, 그리드에서 눈에 띄는 것은 오직 사진이다.
  2. Primary는 회색이 섞인 청색(#2F6390)이다. 따뜻한 라이프스타일 톤과 정반대의 온도이고, 시공 사진에 흔한 우드·베이지 위에 얹혀도 서로 싸우지 않는다.
  3. 중립색은 순회색이 아니라 청색이 아주 미세하게 섞인 쿨 그레이다. 도면·견적서 같은 실무 문서의 인상을 주면서 사진의 색을 왜곡하지 않는다.
  4. Secondary는 흙빛 클레이(#A8623C)로, 감성 장식이 아니라 "인증 시공자"처럼 신뢰 신호에만 쓴다. 아껴 쓰기 때문에 나올 때마다 의미를 갖는다.
  5. 모든 텍스트·버튼 조합은 WCAG AA(4.5:1) 이상이며 대비율을 화면에 그대로 적어 뒀다. 신뢰가 핵심 가치인 서비스는 접근성부터 정직해야 한다.
