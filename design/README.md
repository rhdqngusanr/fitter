## Q8 결정 반영

**이용 방법은 별도 화면을 만들지 않는다.** G-01 랜딩의 `3단계로 끝납니다` 섹션에 `id="how"`를 주고, 헤더 내비 `이용 방법`을 `#how` 앵커로 연결했다. 이 섹션은 `고객으로 / 시공자로` 토글로 3단계와 FAQ 3개가 함께 바뀐다. 화면 목록은 21개 그대로다.
