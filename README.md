# Fitter

반셀프 인테리어 매칭 플랫폼. 개발 포트폴리오 겸 사업 구상 프로젝트.

원하는 인테리어 사진을 올리는 고객과, 자기 시공 포트폴리오를 올리는 개인 시공자를 사진 기준으로 직접 연결한다. 종합업체가 가져가던 중간 마진을 걷어내고 고객은 일감비만 지불하는 구조를 목표로 한다.

## 이 저장소의 구조

`brain/` 폴더가 이 프로젝트의 두뇌다. 옵시디언 볼트로 열어서 쓴다. 기획 판단, 도메인 정의, 설계 결정, 실행 프롬프트가 전부 여기 있고 서로 위키링크로 연결되어 있다. 코드보다 이쪽이 먼저다.

AI 도구(Claude Code, Cursor)로 작업할 때는 루트의 `CLAUDE.md`가 진입점이 되고, 거기서 `brain/00-허브/세션 부팅 프로토콜.md`로 이어진다.

## 옵시디언 연결 방법

옵시디언을 열고 "Open folder as vault"에서 `C:\dev\Fitter\brain`을 선택한다. 볼트 루트의 `Fitter 두뇌 허브.md`가 시작점이다. 그래프 뷰(Ctrl+G)를 켜면 노트 간 연결이 신경망처럼 보인다.

권장 설정은 `brain/90-규약/노트 작성 규칙.md`에 정리해뒀다.

## 현재 상태

Phase 0(디자인 시안) 시작 전. 기술 스택 미정. 진행 상황은 `brain/00-허브/진행 현황판.md`에서 확인.
