## 프롬프트를 쓰는 규칙

**Phase 하나가 끝나면 컨텍스트를 비운다.** Claude Code에서 `/clear`. 대신 결과물은 반드시 `brain/70-산출물/`에 파일로 남기고, 판단은 이 볼트에 반영한다. 파일과 볼트가 남아 있으면 컨텍스트를 비워도 잃는 게 없다.

> 산출물 위치가 2026-07-25에 `docs/`에서 `brain/70-산출물/`로 바뀌었다. `docs/`는 GitHub Pages로 공개되는 폴더라 기획 문서를 두기에 맞지 않는다. 자세한 건 [[노트 작성 규칙]].

**구현 프롬프트는 plan mode로 먼저 돌린다.** Shift+Tab 두 번. 계획을 읽고 승인한 다음 실행. 이거 하나로 헛짓의 절반이 줄어든다.

**한 프롬프트 = 한 기능 = 한 커밋.**

**모든 프롬프트 끝의 "완료 조건"을 지우지 않는다.** AI가 스스로 검증할 기준이 된다.

**결과를 그냥 넘기지 않는다.** "왜 이렇게 했는지 3줄로 설명해줘"를 습관처럼 던진다.

세션을 마칠 때는 [[세션 부팅 프로토콜]]의 4단계를 수행한다.
