## 4편이 공개적으로 말한 것

다음 세션이 이걸 바꾸면 글과 어긋난다. 바꿔도 되지만 **어긋난다는 걸 알고 바꿔야 한다.**

- 화면 19/21, 테스트 203개, 노트 59개·위키링크 1115개
- 쿠키 `sameSite: 'lax'` 문제 때문에 **도메인을 샀다**. 웹과 api 를 같은 사이트로 묶는다
- 색인은 **기본값 차단**. 환경변수로만 열린다
- 에러 트래킹을 네 곳에 붙였고 트레이싱·PII·리플레이 셋은 껐다
- 배포 설정을 `railway.json` 으로 고정했다(마이그레이션은 배포 직전, 헬스체크 경로 지정)
- QC 를 3층으로 나눴고 **2·3층은 부르지 않으면 안 돈다**
- **자동 검사가 잡은 건 3건, 눈으로 잡은 건 11건**이라고 썼다. 화면마다 두세 번 돌렸다는 것도
- **빈도 제한(rate limit)이 아직 없고 그것만 하면 올린다**고 썼다

## 쓸 때 지킨 것

- **수치는 세어보고 쓴다.** 4편의 숫자는 전부 실행해서 확인한 값이다
- **실패를 지우지 않는다.** 되돌린 것과 막힌 것을 항목으로 남긴다.
  1~3편도 그렇게 썼고 그게 이 시리즈의 성격이 됐다
- **볼트는 안 올린다.** 사업 판단이 들어 있어 저장소를 공개로 둔 것과 별개로 유지한다
- 이름·연락처 같은 실데이터는 쓰지 않는다. 화면 예시는 시안의 가상 값을 쓴다
