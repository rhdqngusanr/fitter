# 2026-07-26 — 없던 화면 넷

앞선 [[2026-07-26 - 시안 재대조]]가 "API 는 있는데 화면이 없다"고 남긴 자리들의
시안을 받아서 만들었다. **셋 다 서버는 완성돼 있었고 화면만 없었다** —
그래서 이 작업은 기능 추가가 아니라 **구멍 메우기**였다.

## 무엇을 했는가

| 시안 | 경로 | 없어서 막혀 있던 것 |
| --- | --- | --- |
| P-01 프로필 편집 | `/pro/profile` | **신규 시공자가 등록을 마칠 수 없었다** |
| C-03 의뢰 상세(내 것) | `/requests/[id]` | 고객이 **자기 의뢰를 마감할 수 없었다** |
| A-01 승인 큐 | `/admin` | **승인이 psql 작업이었다** |
| A-02 신고 큐 | `/admin/reports` | 같음 |
| G-01 이용 방법 | `/#how` | [[열린 질문]] Q8 (화면을 만들지 않기로) |

**남은 화면은 G-04 알림 목록 · G-05 설정 둘뿐이다.** 둘 다 [[백로그]] B-05 · B-08 로
의도적으로 축소한 것이고, 21개 중 19개가 있다.

상세한 대조 내용은 [[시안 대조 결과]] "2차" 절에 화면별로 있다. 여기는 그날의 판단만 적는다.

## 세 화면이 없어서 실제로 무엇이 깨져 있었나

이게 이 작업의 핵심이다. 화면이 없다는 건 "기능이 덜하다"가 아니라 **경로가 끊겨 있다**는
뜻이었다.

**P-01.** 역할을 PRO 로 고르면 `ProProfile` 행이 생기지만 활동명이 빈 채로 남는다.
`/pros` 의 공개 조건이 `businessName != ''` 이라 목록에 안 뜨고, 공종·지역이 비어서
`/jobs` 매칭도 무의미하다. **관리자가 승인해줘도 같다.** 즉 시공자가 이 서비스에
등록을 마칠 수 있는 경로가 없었다.

**C-03.** `POST /reference-requests/:id/close` 는 있는데 부르는 화면이 없었다.
고객은 자기 의뢰를 영원히 열어둘 수밖에 없었다. 그리고 `/requests/mine` 은
**카드에 링크가 없어서** 어디로도 이어지지 않는 목록이었다 — C-03 을 만들어도
도달할 수 없었으므로 목록 카드를 링크로 만드는 것까지가 한 작업이었다.

**A-01·A-02.** 승인 API 는 [[백로그]] B-02 때부터 다 있었다. 더 나쁜 건
**ADMIN 계정을 만들 방법이 없었다**는 것이다 — `POST /me/profile` 은 CUSTOMER/PRO 만
받고(그게 맞다), 주석은 "시드로만 만든다"는데 **어느 시드도 만들지 않았다.**
`prisma/seed-admin.ts` 로 메웠다.

## 무엇을 결정했는가

### 시안이 지어낸 숫자는 넣지 않는다 (계속)

1차 대조에서 세운 원칙을 그대로 이었다. 이번에 뺀 것들:
`시공 87건` · `평균 응답 3시간` · `노출된 시공자 14명` · `컨택을 2배 더 받습니다` ·
`평균 처리 6시간` · `이번 주 신고 11건`(→ 실제로 셀 수 있는 `최근 7일` 로 바꿨다).

**반대로 셀 수 있는 건 진짜로 셌다.** "저장하지 않은 변경 3건"은 8개 필드를 원본과
비교해 세고, "마지막 저장"은 `updatedAt` 을 쓰고, 승인 큐의 위험 신호는 여섯 가지
사실에서 계산한다.

### 저장할 곳이 없는 입력은 만들지 않는다

시안에는 저장 경로가 없는 컨트롤이 여럿 있었다 — 프로필 사진 업로드, 서류 파일,
제안 `숨기기`, 마감 사유 칩 넷, 신고 조치 `경고 · 계정 정지`.

**고르게 해두고 버리면 물어본 척만 하는 화면이다.** 넷을 그려놓고 둘만 동작하게
만드는 것보다 둘만 두는 게 낫다.

### 정본이 둘이 될 입력도 만들지 않는다

P-01 의 `예상 비용 공개` 토글을 뺐다. `isCostPublic` 은 **사례(P-02)의 속성**이고
프로필에 또 두면 같은 사실의 정본이 둘이 된다. [[확장 규약]]이 금지하는 모양이다.

### 없는 안전장치를 있다고 말하지 않는다

관리자 사이드바의 "모든 조치는 감사 로그에 남습니다"를 지웠다. **감사 로그가 없다.**
없는 안전장치를 있다고 하면 운영자가 그것을 믿고 행동한다. 지금 남는 건 알림과
상태 컬럼뿐이므로 그것만 적었다.

### 화면 없는 메뉴로 링크를 걸지 않는다

관리자 사이드바의 `회원 · 의뢰 · 감사 로그` 셋을 뺐다. 링크를 걸면 404 고,
회색으로 두면 "곧 나온다"는 약속이 된다. 둘 다 하지 않는다.

## 서버가 이미 정한 주소를 따랐다

P-01 의 경로는 내가 고른 게 아니다. `POST /me/profile` 이 PRO 에게
`next: '/pro/profile'` 을 **이미 돌려주고 있었다.** 웹은 그걸 무시하고 자기 상수로
`/portfolios/new` 로 보냈다 — 착지점의 정본이 둘이었고 이제 하나다.

이런 걸 찾으려면 **응답을 읽어야 한다.** 화면 코드만 보면 상수가 하나뿐이라 문제가 안 보인다.

## 규칙을 어긴 코드를 두 개 고쳤다

작업 범위 안에서 드러난 것들이다.

1. **`AdminController` 가 Prisma 를 직접 불렀다.** [[구조적 원칙]]과 CLAUDE.md 의
   「절대 하면 안 되는 것」이 금지한 것이다. 위험 신호 계산이 붙으면서 컨트롤러에 둘
   수 없는 크기가 됐으므로 `AdminService` 로 뽑았다.
2. **`profile_completeness` 컬럼이 항상 0이었다.** 처음부터 있었는데 아무도 쓰지
   않았다. 계산을 `packages/domain/user/pro-profile.ts` 에 두고 저장 트랜잭션 안에서
   컬럼에 쓴다. `user/index.ts` 가 "아직 여기 없는 것"으로 적어둔 파일이 정확히 이거였다.

## 브라우저에서 잡은 결함 9건

전부 타입·lint·테스트를 통과하는 것들이었다. **열어보지 않으면 하나도 안 보인다.**

| 화면 | 무엇 |
| --- | --- |
| P-01 | 완성도 0%인 빈 프로필에 `승인 시공자` 배지가 붙었다 — `isApproved` 를 `isNew` 보다 먼저 봤다 |
| P-01 | `공개 프로필 보기` 가 404 로 갔다 — 승인만 확인했는데 조건은 셋이다 |
| P-01 | 공종 13종이 578px 칸에 1056px 로 깔려 6개가 숨은 스크롤 뒤에 있었다 |
| P-01 | 검증 오류 상태가 영원히 안 떴다 — 서버는 `details.issues[].path`, 화면은 `details.field` |
| C-03 | 제안 3건이 깔린 화면에서 우측 패널이 "제안을 기다리는 중"이라고 했다 |
| C-03 | 다시 열기 400 에 "필수 항목이 비어 있습니다"만 떠서 무엇을 고칠지 알 수 없었다 |
| A-01 | `되돌리기` 토스트가 "1명 반려했습니다"라고 해서 새 조치로 읽혔다 |
| A-01 | 로드 실패가 머리글만 남은 표로 보여 "0건"으로 읽혔다 |
| G-01 | 내가 쓴 FAQ 문장이 틀렸다 — 아래 참고 |

마지막 것이 가장 뼈아프다. 시안 카피의 거짓말 셋을 고치면서 **내가 새 거짓말을 하나
심었다.** "한 의뢰에 같은 시공자가 두 번 제안할 수 없습니다"라고 썼는데, 부분 유니크
인덱스가 막는 건 `(requester, receiver) WHERE status='REQUESTED'` 다 — 의뢰 단위가
아니라 **상대 단위**다. 인덱스 정의를 직접 열어보고서야 잡았다.

**카피에 규칙을 적을 땐 그 규칙의 정의를 봐야 한다.** 기억으로 쓰면 그럴듯한 거짓말이 된다.

## QC 가 세 번 잡았다

`pnpm qc` 가 코드에서는 error 라서 커밋 전에 걸린다. 이번에 잡힌 것들.

1. **전화번호 리터럴** — 플레이스홀더에 `01012345678` 을 적었다. 형식 설명으로 바꿨다.
2. **`process.env` 직접 읽기** — 시드 스크립트에서 `ADMIN_EMAIL` 을 읽었다.
   규칙에 예외를 내는 대신 **인자 하나로 통로를 줄였다.**
3. **금지어 `견적`** — 시안 카피 "견적서를 읽을 줄 몰라도 됩니다"를 그대로 옮겼다.
   [[도메인 용어집]]이 MVP 에서 금지한 단어다. → [[시안 검수 결과]] 12번

그리고 **검사기 자신의 오탐 하나를 고쳤다.** `expansion/region-free-text` 가
`[가-힣]+(구|시|동)` 을 문자열 아무 곳에서나 찾아서 **`자동으로` 의 `동`** 이 주소로
잡혔다. 행정구역 접미사는 낱말 끝에서만 센다. 고친 뒤 진짜 위반을 잠깐 심어
여전히 잡는지 확인했다.

## 환경에서 또 배운 것

**`.next` 를 지워야 했다.** 빌드를 개발 서버가 켜진 상태로 돌린 뒤 화면이 통째로
비었다 — SSR HTML 에는 내용이 있는데 브라우저 DOM 은 빈 Suspense 경계뿐이고
콘솔 에러도 서버 에러도 없었다. 지난번에는 서버 재시작으로 됐지만 이번엔 안 됐다.

```bash
rm -rf apps/web/.next
```

**빌드를 돌릴 거면 개발 서버를 먼저 끄는 게 맞다.** → [[진행 현황판]] 경고 갱신

**데모 계정으로는 화면을 볼 수 없다.** `passwordHash` 가 일부러 null 이다(뒷문 방지).
C-03 을 보려면 API 로 가입시킨 뒤 Prisma 로 의뢰·제안을 붙여야 했다.
직접 해시를 만들어 넣으려다 실패했는데 **그게 맞다** — 해시는 서버가 만들어야 한다.

## 그리고 화면 QC 를 자동화했다

같은 세션 후반에 붙였다. **계기는 사용자의 질문이었다** — "자동 qc로 화면 눌러보는
테스트도 통과한 거야?" 답은 **아니오**였다. `pnpm qc` 는 브라우저를 열지 않고
`pnpm test` 는 웹 테스트가 0개다. **결함 11건은 전부 손으로 잡은 것이고 어디에도
남지 않았다.**

즉 없는 건 "클릭하는 능력"이 아니라 **반복**이었다. 매번 내가 즉석에서 무엇을 볼지
정하니 세션이 바뀌면 안 돈다.

### 3층으로 나눈 이유

이번 결함 11건을 도구별로 나눠보니 **절반씩 갈렸다.**

- **단정문으로 잡히는 것** — 빈 화면, 숨은 컨트롤, 안 뜨는 에러 상태, 조건부 404
- **LLM 만 잡는 것** — 문장끼리의 모순, 버튼의 약속과 다른 이동,
  카피가 인덱스 정의와 다른 규칙을 말하는 것

**단정문은 어긋남을 잡고 에이전트는 거짓말을 잡는다.** 하나만으로는 절반이 남는다.

### 만든 것

| 층 | 무엇 | 자동인가 |
| --- | --- | --- |
| 1 | `scripts/qc/checks/routes.mjs` — `pnpm qc` 의 일곱 번째 검사 | **자동** |
| 1 | `scripts/qc/hooks/stop-web-check.mjs` — Stop 훅 | **자동** |
| 2·3 | `.claude/skills/qc-screens/SKILL.md` — `/qc-screens` | 불러야 돈다 |
| 2·3 | `.claude/agents/frontend-qc.md` — 화면당 서브에이전트 | 같음 |

목록의 근거는 [[화면 QC 목록]]에 있다. **R1~R7·J1~J7 전부 실제로 겪은 결함에서 왔고
상상한 항목은 없다.**

`routes` 는 **두 번 겪은 결함**이 근거다 — `프로필 전체 보기` 가 404 였고, C-03 을
만들었는데 목록 카드에 링크가 없어 도달할 수 없었다. 둘 다 타입 검사를 통과한다.
링크가 문자열이기 때문이다. 심어서 양방향 확인했다.

### 훅이 하는 일의 절반은 "말하는 것"이다

Stop 훅은 1층을 돌리고 나서 이렇게 말한다.

```
⚠️ 화면 QC(2·3층)는 아직 안 돌았다 — 렌더 결과·상태·문장 모순은 `/qc-screens` 가 본다.
```

**그 문장이 이 훅의 존재 이유다.** `pnpm qc` 통과가 "화면을 검사했다"로 읽히는 것이
이 프로젝트가 실제로 겪은 문제였다 — 시안과 다른 화면이 전부 통과한 채로 쌓였다.

**훅은 막지 않는다.** 막으면 고치라고 되돌리는 루프가 생기고, error 가 의도된 것일 때
빠져나갈 방법이 없어진다. 판단은 사람이 한다.

### Playwright 는 넣지 않았다

이 환경의 Windows Application Control 이 서명 없는 네이티브 모듈을 막은 전례가 있다
(`@swc/core` → vitest 포기). Playwright 는 브라우저 바이너리를 따로 내려받는데 같은
정책에 걸릴 수 있고 **설치 시도를 해봐야 안다.** → [[열린 질문]] Q11

넣으면 회귀가 막히지만 **절반만** 막힌다. 지금은 판단 층을 굳히는 게 먼저였다.
